WEEK 1 VIVA NOTES

1. An attribute is information kept by an object, such as a car's speed or color. A behaviour is something the object can do, such as start, drive, or turn.

2. new Car() makes a new Car object and runs the constructor.

3. bmw is a reference variable. It points to the Car object instead of storing the whole object inside the variable.

4. bmw and tesla are made from the same class, but they are separate objects. That is why they can have different brands, speeds, fuel levels, and directions.

5. In setDetails(), this.brand is the field that belongs to the current object. brand is the value received by the method.

6. The dot operator is used to access something through an object reference. For example, bmw.startEngine() runs startEngine() on the BMW object.

7. I made the fields private so they cannot be changed directly from Main. The public methods can check the rules before changing a value.

8. Car describes what a car object stores and does. Main is separate because it creates the objects and runs the examples.
